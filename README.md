# Aurora Music

**Aurora Music** — музыкальный центр для Windows и Android. На компьютере это **Lumen**: локальный плеер в стиле Aurora Standalone, захват системного звука и Wi‑Fi‑трансляция. На телефоне — **Aurora Music**: тёмный интерфейс Aurora Standalone с фиолетово‑бирюзовым акцентом, музыка с ПК, файлы из памяти телефона, онлайн‑каталог и фоновое воспроизведение.

## Два приложения — один плеер

| | Windows — Lumen | Android — Aurora Music |
|---|---|---|
| **Технологии** | C# / WPF / .NET Framework 4.8 | Kotlin / WebView / MediaSession |
| **Музыка** | папка на компьютере и онлайн‑каталог | библиотека с ПК, файлы с телефона и онлайн‑каталог |
| **Главные фишки** | WASAPI loopback, HTTP‑трансляция | foreground service, уведомление и lock screen |
| **Интерфейс** | Aurora Standalone в WPF, без сторонних UI‑библиотек | Aurora Standalone: глубокий тёмный фон, фиолетовый и бирюзовый акценты |

Общий веб‑плеер (`src/Net/WebUi.html`) открывается с телефона или другого ПК по адресу вида `http://192.168.1.215:8737/` и используется внутри APK. Поэтому главная, поиск, медиатека, онлайн, эфир, избранное и мини‑плеер выглядят одинаково везде.

## Возможности

### Windows — Lumen

- **Локальный плеер.** Выбор папки, рекурсивный поиск треков, очередь, обложки из ID3‑тегов MP3, перемотка, громкость и автопереход.
- **Захват системного звука.** WASAPI loopback ловит всё, что играет на компьютере: браузер, другой плеер, игру или видео.
- **Трансляция по локальной сети.** Встроенный HTTP‑сервер отдаёт веб‑плеер с плейлистом и вкладками «Онлайн» и «Прямой эфир».
- **Aurora Standalone.** Глубокий тёмный фон, мягкие поверхности, фиолетово‑бирюзовые градиенты, большие радиусы и анимации. WPF без сторонних UI‑библиотек.
- **Общий веб‑плеер.** Тёмная палитра Aurora Standalone: главная с подборками, поиск, медиатека, онлайн‑каталог, мини‑плеер и полноэкранный режим.
- **Онлайн‑музыка.** Вкладка «Онлайн» ищет свободные записи в Internet Archive, включает радио Radio Browser и прямые MP3/AAC/OGG‑потоки. Онлайн‑треки встают в общую очередь и сохраняются в медиатеке.
- **Портативная сборка.** Один `.exe`, которому нужен только .NET Framework 4.8.

### Android — Aurora Music

- **Музыка с ПК.** Подключение по адресу из Lumen; адрес запоминается и используется при следующих запусках.
- **Файлы с телефона.** Кнопка «+» в медиатеке открывает аудиофайлы из памяти устройства или SD‑карты без подключения к компьютеру.
- **Онлайн‑музыка.** Та же вкладка «Онлайн»: Archive.org, интернет‑радио и прямые ссылки — с общей очередью, избранным и фоновым воспроизведением.
- **Новый интерфейс.** Главная с приветствием, быстрыми плитками и подборками, вкладка поиска, фильтры «Все / Избранное / Онлайн / С телефона», сердечки в списке треков.
- **Фоновое воспроизведение.** Foreground service удерживает звук при свёрнутом приложении и заблокированном экране.
- **Управление с экрана блокировки.** Уведомление и `MediaSession`: пауза, следующий/предыдущий трек, название и исполнитель.
- **Прямой эфир.** Системный звук Windows можно слушать на телефоне в реальном времени.
- **Избранное и визуализаторы.** Сердце в списке и полноэкранном плеере сохраняется в `localStorage`; три режима фоновой анимации.

## Быстрый старт

### Windows

1. Скачайте `Lumen-1.0-win64.zip` и распакуйте архив в удобную папку.
2. Запустите **`Lumen.exe`**.
3. Выберите «Локальная музыка» и укажите папку с аудиофайлами или откройте «Захват звука».
4. Если Windows спросит про брандмауэр, разрешите Lumen доступ в **частных сетях**.
5. Ссылку для телефона можно скопировать из карточки «Трансляция по Wi‑Fi».

### Android

1. Скачайте `AuroraMusic.apk` из релиза и установите его (разрешите установку из неизвестных источников).
2. Запустите **Lumen** на компьютере: телефон и ПК должны быть в одной Wi‑Fi‑сети.
3. Откройте Aurora Music и в карточке **«Подключение к ПК»** введите адрес из Lumen, например `192.168.1.215:8737`.
4. Нажмите **«Подключить»** — плейлист появится в разделе **«Медиатека»**. Без ПК нажмите **«+»** в медиатеке, чтобы открыть файлы с телефона.
5. На Android 13+ разрешите уведомления, чтобы работал пульт на экране блокировки.

Подробности — в [android/README.md](android/README.md).

## Как это работает

```
Lumen (Windows)                         Aurora Music (Android)
┌──────────────────────────┐            ┌──────────────────────────┐
│ WPF UI                   │            │ Kotlin + WebView         │
│  ├─ Media Foundation     │            │  ├─ общий WebUi.html     │
│  ├─ WASAPI loopback      │  Wi‑Fi     │  ├─ PlaybackService      │
│  └─ HTTP-сервер :8737 ───┼───────────►│  └─ MediaSession         │
└──────────────────────────┘            └──────────────────────────┘
```

- **Lumen** отдаёт `/api/tracks`, `/audio/N`, `/live.wav`, `/proxy` и сам веб‑плеер.
- **APK** загружает те же ассеты локально, а при подключении к ПК обращается к его HTTP‑серверу.
- **PlaybackService** не декодирует звук сам: WebView остаётся аудиодвижком, а сервис держит процесс живым и принимает команды с уведомления, экрана блокировки и гарнитуры.

## Онлайн‑музыка

Вкладка **«Онлайн»** в веб‑плеере и APK собирает музыку из открытых источников — без аккаунтов, API‑ключей и DRM:

- **Internet Archive** — каталог свободной музыки: инди, джаз, классика, живые записи. Поиск идёт по коллекциям `netlabels`, `audio_music`, `opensource_audio` и `etree`; аудиокниги, подкасты и радиоспектакли отфильтрованы.
- **Radio Browser** — интернет‑радио: станции в MP3, AAC и OGG. HLS‑плейлисты (`.m3u8`) не поддерживаются.
- **Прямая ссылка** — любой доступный MP3/AAC/OGG‑поток, например адрес интернет‑радио.

Онлайн‑треки живут в той же очереди, что и локальные и телефонные: работают следующий/предыдущий трек, избранное, медиатека (фильтр «Онлайн»), мини‑плеер и визуализатор. Очередь сохраняется в `localStorage` (`aurora.online`).

**Как идёт звук.** На компьютере веб‑плеер запрашивает онлайн‑аудио через `/proxy?url=…`, который подставляет Lumen: это снимает ограничения CORS, сохраняет работу Web Audio‑анализатора и позволяет играть потоки без CORS‑заголовков. Поэтому для онлайн‑музыки на телефоне Lumen должен быть запущен, а телефон и ПК — в одной сети. Прямые ссылки на Archive.org работают и без прокси, но радио без CORS может молчать.

**Чего нет.** Spotify, Apple Music, VK Музыка и Яндекс Музыка не отдают полные треки сторонним плеерам без авторизации и DRM, поэтому их каталоги здесь не подключены. YouTube‑риппинг и обход DRM не используются.

## Поддерживаемые форматы

За воспроизведение на Windows отвечает Media Foundation, поэтому список зависит от кодеков системы. Обычно работают:

`MP3`, `WAV`, `FLAC`, `M4A`, `AAC`, `WMA`, `OGG`, `OPUS`, `AIFF`.

Для лучшего результата используйте MP3/WAV/AAC. В Windows 10/11 N‑редакций может потребоваться установить Media Feature Pack. Android‑плеер воспроизводит то, что поддерживает WebView/система (MP3, FLAC, WAV, M4A и другие распространённые форматы).

## Требования

- **Windows:** Windows 10 или 11 (64‑битная), .NET Framework 4.8, звуковое устройство вывода;
- **Android:** Android 7.0+ (minSdk 24), свободное место для APK;
- **Сеть:** общая Wi‑Fi/LAN‑сеть для музыки с ПК и прямого эфира; интернет — для вкладки «Онлайн».

## Сборка из исходников

### Windows

Нужен только встроенный в Windows компилятор .NET Framework 4.x:

```powershell
# в папке AuroraMusic
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build.ps1
```

Появятся `dist\Lumen.exe` и `dist\Lumen-1.0-win64.zip`. Скрипт сам создаёт иконку и встраивает XAML‑ресурсы.

### Android

Нужны JDK 17, Android SDK 34 и Gradle (или Android Studio). В репозитории есть Gradle Wrapper:

```powershell
cd android
.\gradlew.bat assembleDebug
```

Либо из корня:

```powershell
.\build-apk.ps1
```

Скрипт синхронизирует `src\Net\WebUi.html` в ассеты APK, собирает `assembleDebug` и кладёт результат в `dist\AuroraMusic.apk`. Пути к JDK/SDK можно переопределить через `JAVA_HOME` и `ANDROID_HOME`.

## Приватность и ограничения

- Локальная музыка и эфир не покидают вашу сеть: нет облака и аккаунтов. Вкладка «Онлайн» обращается к Internet Archive и Radio Browser; аудио на телефоне идёт через ваш ПК.
- Захваченный звук **не записывается на диск**, а передаётся только открытым клиентам в локальной сети, пока включён захват.
- У локального веб‑сервера нет пароля: любой, кто знает адрес и находится в вашей сети, может открыть плейлист или эфир. Не включайте трансляцию в недоверенных сетях.
- Защищённый DRM‑звук (например, некоторые стриминговые сервисы) может не попадать в loopback.
- Трансляция работает в пределах локальной сети. Для доступа из интернета понадобится отдельный туннель/проброс порта — в этой версии его нет.
- Windows‑приложение не подписано цифровой подписью, поэтому SmartScreen может показать предупреждение при первом запуске. APK собран в debug‑варианте и подписан отладочным ключом.
