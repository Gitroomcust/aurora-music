# Lumen

**Lumen** — маленький музыкальный центр для Windows в стиле Material You 3. Он умеет играть музыку из локальной папки и захватывать системный звук, чтобы слушать его на телефоне или другом компьютере в той же Wi‑Fi‑сети.

![Главный экран Lumen](docs/welcome.png)

## Что внутри

- **Приветствие с именем пользователя Windows.** Lumen берёт имя из учётной записи ПК (`Environment.UserName`) и показывает его на стартовом экране.
- **Две большие градиентные кнопки:** «Локальная музыка» и «Захват звука».
- **Локальный плеер.** Выбор папки, рекурсивный поиск треков, очередь, обложки из ID3‑тегов MP3, перемотка, пауза, следующий/предыдущий трек и громкость.
- **Захват системного звука.** WASAPI loopback ловит всё, что играет на компьютере: браузер, другой плеер, игру, видео.
- **Трансляция по локальной сети.** Встроенный веб‑плеер открывается по адресу вида `http://192.168.1.215:8737/` на телефоне или другом ПК. В нём есть плейлист и вкладка «Прямой эфир».
- **Material You 3.** Мягкие тональные поверхности, большие радиусы, градиенты, анимации и аккуратная типографика. Интерфейс собран на WPF без сторонних UI‑библиотек.

## Как запустить

1. Распакуйте папку с программой и запустите **`Lumen.exe`**.
2. На приветственном экране выберите нужный режим.
3. Для локальной музыки нажмите «Выбрать папку» и укажите папку с аудиофайлами.
4. Для трансляции откройте «Захват звука» и нажмите круглую кнопку, если захват ещё не запущен.
5. Скопируйте ссылку из карточки «Трансляция по Wi‑Fi» и откройте её на другом устройстве.

### Веб‑плеер

- Открывается автоматически при запуске Lumen (порт `8737`, если занят — следующий свободный).
- На странице две вкладки: **«Моя музыка»** (файлы из выбранной папки) и **«Прямой эфир»** (системный звук).
- Устройство должно быть в той же локальной сети.
- В Windows может появиться запрос брандмауэра — разрешите Lumen доступ в **частных сетях**.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | пауза / воспроизведение |
| `Esc` | вернуться на главный экран |
| `Ctrl + →` | следующий трек |
| `Ctrl + ←` | предыдущий трек |

## Поддерживаемые форматы

За воспроизведение отвечает Media Foundation, поэтому список зависит от кодеков Windows. Обычно работают:

`MP3`, `WAV`, `FLAC`, `M4A`, `AAC`, `WMA`, `OGG`, `OPUS`, `AIFF`.

Для лучшего результата используйте MP3/WAV/AAC. В Windows 10/11 N‑редакций может потребоваться установить Media Feature Pack.

## Требования

- Windows 10 или Windows 11 (64‑битная);
- .NET Framework 4.8 (входит в состав актуальных версий Windows);
- звуковое устройство вывода;
- для веб‑плеера — браузер и общая Wi‑Fi/LAN‑сеть.

## Где хранятся настройки

- `%LOCALAPPDATA%\Lumen\settings.ini` — последняя папка и громкость;
- `%LOCALAPPDATA%\Lumen\lumen.log` — технический журнал.

Если запись в `%LOCALAPPDATA%` недоступна, Lumen использует папку рядом с `.exe`.

## Приватность и ограничения

- Всё работает локально: нет облака, аккаунтов и отправки данных в интернет.
- Захваченный звук **не записывается на диск**, а передаётся только открытым клиентам в локальной сети, пока включён захват.
- У локального веб‑сервера нет пароля: любой, кто знает адрес и находится в вашей сети, может открыть плейлист или эфир. Не включайте трансляцию в недоверенных сетях.
- Защищённый DRM‑звук (например, некоторые стриминговые сервисы) может не попадать в loopback.
- Трансляция работает в пределах локальной сети. Для доступа из интернета понадобится отдельный туннель/проброс порта — в этой версии его нет.
- Приложение не подписано цифровой подписью, поэтому Windows SmartScreen может показать предупреждение при первом запуске.

## Сборка из исходников

Нужен только встроенный в Windows компилятор .NET Framework 4.x:

```powershell
# в папке AuroraMusic
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build.ps1
```

Готовый файл появится в `dist\Lumen.exe`. Скрипт сам создаёт иконку и встраивает XAML‑ресурсы.

## Структура проекта

```
src/
  Audio/       MFPlay-плеер, WASAPI loopback, ID3, live-шина
  Net/         TCP HTTP-сервер и веб-плеер
  Controls/    кастомный waveform
  *.xaml       тема и экраны
tools/         иконка и подготовка скриншотов
docs/          иллюстрации
dist/          собранное приложение (не попадает в git)
```
