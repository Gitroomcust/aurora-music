# Changelog

## 1.0.0 — 2026-10-19

Первый публичный выпуск Lumen.

### Добавлено

- приветственный экран в стиле Material You 3 с именем пользователя Windows;
- локальный плеер с выбором папки, очередью, перемоткой, громкостью и автопереходом;
- чтение ID3-тегов и обложек MP3;
- захват системного звука через WASAPI loopback;
- live-трансляция PCM-звука по локальной сети (HTTP chunked WAV);
- встроенный веб-плеер с плейлистом и вкладкой «Прямой эфир»;
- тёмный визуализатор уровня сигнала и пиковый индикатор;
- сохранение последней папки и громкости;
- портативный Windows-сборщик на встроенном `csc.exe` без сторонних зависимостей.

### Ограничения

- трансляция доступна только в локальной сети;
- у веб-сервера нет авторизации;
- защищённый DRM-звук может не попадать в loopback;
- поддерживаемые форматы зависят от кодеков Media Foundation в Windows.
