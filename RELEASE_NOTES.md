# Lumen 1.0

Первый релиз музыкального центра для Windows в духе Material You 3.

## Что умеет

- запускается с приветственным экраном в стиле Material You 3;
- играет музыку из локальной папки: MP3, WAV, FLAC, M4A, AAC, WMA, OGG, OPUS, AIFF;
- читает ID3-обложки и теги MP3;
- захватывает системный звук со всех приложений через WASAPI loopback;
- транслирует звук по локальной сети;
- отдаёт веб-плеер с плейлистом и прямым эфиром для телефона или другого ПК.

## Установка

1. Скачайте `Lumen-1.0-win64.zip`.
2. Распакуйте архив в удобную папку.
3. Запустите `Lumen.exe`.
4. Разрешите приложению доступ в частных сетях, если Windows спросит про брандмауэр.

Требования: Windows 10/11 x64, .NET Framework 4.8, звуковое устройство вывода.

## Трансляция

После запуска Lumen откройте на телефоне адрес из карточки «Трансляция по Wi‑Fi» — например, `http://192.168.1.215:8737/`. Устройства должны быть в одной сети.

## Важно

- Трансляция работает только в локальной сети и не имеет пароля.
- Захваченный звук не записывается на диск.
- Приложение не подписано, поэтому SmartScreen может показать предупреждение.
